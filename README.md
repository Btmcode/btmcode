# btmcode

BTMCode — Software, AI & Product Engineering.

## Source

This repository mirrors the website source currently deployed on Vercel.

## Deployment

The site is served as a static website on Vercel. Contact form email delivery uses a server-side Vercel Function and the `RESEND_API_KEY` environment variable.

## Security

Never commit `.env` files, API keys, tokens, private credentials, or deployment secrets.
