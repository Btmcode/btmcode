Image hosting & CDN API
PROJECT OVERVIEW

Projenin amacı

API-first image hosting ürünü; çoklu boyut varyantları, otomatik WebP dönüşümü, kullanıcı API anahtarları, görsel yönetimi, API dokümantasyonu ve ödeme/billing ekranlarını bir araya getiriyor.

CORE FEATURES

Öne çıkan işlevler

  • WebP dönüşümü ve görsel sıkıştırma iş akışı
  • Thumbnail, medium ve large boyut varyantları
  • Korumalı kullanıcı paneli, upload ve görsel kütüphanesi
  • API key yönetimi ve REST API dokümantasyonu
  • Billing, ödeme, kullanıcı ve güvenlik yönetimi için admin modülleri
